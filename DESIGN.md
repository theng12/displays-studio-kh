# Menu-bar panel

**Operate.** Follow the established KH utility shell, not a new visual identity. This is a compact display console: system type, native sliders, one accent, and a single list, divided by monitor. Brightness comes first; contrast and volume follow only if available. Every slider pairs a visible label with its value. The hardware value is shown only after a successful read.

The shortcut hint and version stay below the display list. Settings and What's New are reachable without a sidebar. Follow the system light or dark appearance and retain a visible keyboard focus ring. Report a disconnected or unsupported screen in place, and offer an explicit refresh, not an automatic loop.
